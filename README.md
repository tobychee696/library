# 幼稚園新書資料輸入工具（v1.0）

用手機 Chrome 批量拍攝圖書版權頁 → 自動辨識文字 → 老師核對 → 匯出 Excel 97–2003（.xls）。

- 免費、無後端、無月費、免安裝
- 每部手機獨立儲存，最多 **400 條**
- 所有資料只存在該手機的瀏覽器內（IndexedDB），不會上傳到任何伺服器
- 首次開啟需連網下載辨識引擎（約 10MB），之後可離線使用

---

## 一、一次性上線（約 10 分鐘）

需要一個免費 GitHub 帳戶（或 Netlify 帳戶，二選一）。

### 方法 A：GitHub Pages（建議）

1. 登入 <https://github.com>，按右上角 **+ → New repository**。
2. Repository name 例如 `library-tool`，選 **Public**，按 **Create repository**。
3. 在新建的 repo 頁面按 **uploading an existing file**。
4. 把這個資料夾內**所有檔案及資料夾**拖進去（必須包含 `vendor` 與 `icons` 兩個資料夾），按 **Commit changes**。
5. 進入 **Settings → Pages**。
6. **Source** 選 `Deploy from a branch`，Branch 選 `main`、資料夾選 `/ (root)`，按 **Save**。
7. 等 1–2 分鐘，頁面上方會出現網址，例如：
   `https://你的帳號.github.io/library-tool/`
8. 用電腦或手機打開該網址，見到「批量拍下版權頁」即成功。

### 方法 B：Netlify Drop

1. 先把整個 `library-tool` 資料夾壓縮成 zip。
2. 打開 <https://app.netlify.com/drop>，把 zip 拖進去。
3. 取得網址（例如 `https://xxxx.netlify.app`）即完成。

### 加到手機主畫面

Android Chrome 開啟網址 → 右上角 **⋮** → **加到主畫面／安裝應用程式**。
之後像 App 一樣點開，可全螢幕使用。

> 注意：GitHub Pages 是公開網址，任何知道網址的人都可「打開」這個工具，但**看不到你的資料**（資料只在各自手機內）。

## 二、日常使用流程

1. **拍攝**：按「拍照」（單張）或「從相簿選多張」（批量）。相片會自動排隊辨識。
2. **待校對**：逐張點開，核對五項必填：
   - 館藏分類（12 個選項）
   - 條碼（ISBN）
   - 書名
   - 文字作者（只填作者，不填繪者／譯者）
   - 編號／索書號（R / I / C / E）
3. 有錯直接改；按 **已確認** 即完成（會自動返回清單）。
4. 全部完成後到 **更多 → 匯出 Excel**。
5. 匯出檔名為 `library_YYYYMMDD-HHmm.xls`，可用 Excel 97–2003 或新版 Excel 開啟。

### 索書號規則（工具會自動建議，老師可改）

| 情況 | 字母 |
|---|---|
| 宗教圖書 | **R**（優先於所有分類） |
| 非宗教工具書／教師參考書 | **I**（優先於語言分類） |
| 其餘中文書 | **C** |
| 其餘英文書 | **E** |

雙語書由老師判斷；工具會依「作者名是中文還是英文」建議 C 或 E。

### Excel 欄位

依校內範本 `library_database.xls` 的 11 欄輸出：

`資源分類`（固定「書本」）、`館藏分類`、`條碼`、`書名`、`作者`、`編號/索書號`、`出版社`、`經費來源`（留空）、`價錢`（留空）、`書本語言`（留空）、`關鍵字`（留空）。

只會匯出狀態為 **已確認** 的資料。

## 三、400 條上限

- 第 400 條之後不能再新增，畫面會顯示「儲存量已滿（400 / 400）」。
- 依提示：**先匯出 Excel → 再按「全部清除」**，即可開始下一批。
- 建議每 50–100 本就匯出一次，避免手機遺失或瀏覽器資料被清除。

---

## 四、重要注意事項

- **不要用無痕模式**：關閉視窗後資料會消失。
- **不要清除 Chrome 的網站資料／儲存空間**，否則本機資料會一併刪除。
- 換手機、換瀏覽器、重設手機：舊資料不會跟隨，請先匯出。
- 不同老師的手機各自獨立；合併時各自匯出 Excel，再把資料列貼到同一份範本。
- 匯出前請確認已按「已確認」；「草稿／待校對」不會寫入 Excel。

---

## 五、更新工具

重新上載 `index.html`、`app.js`、`styles.css`、`sw.js` 到同一位置即可。
程式會優先讀取網絡上的最新版本，離線時自動用快取；老師重新整理便會更新。

## 六、檔案結構

```
index.html            介面
styles.css            樣式
app.js                全部邏輯（拍攝、OCR、校對、儲存、匯出）
sw.js                 Service Worker（離線快取）
manifest.webmanifest  PWA 設定
icons/                主畫面圖示
vendor/               Tesseract.js（OCR）、SheetJS（Excel）、繁中／英文語言包
```

## 七、技術說明

- OCR：Tesseract.js 5（`chi_tra` + `eng`，fast 模型），全部在本機執行，相片不會上傳。
- Excel：SheetJS 0.20，輸出 BIFF8（Excel 97–2003），保留範本欄寬。
- 儲存：IndexedDB；相片壓縮至長邊 1600px 後儲存，縮圖用於清單。
- 上限：400 條（含相片與資料）。
