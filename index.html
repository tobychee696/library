使用說明

  1. 先到「辨識服務」貼上 API key（每部手機一次）。
  2. 拍攝或選取版權頁，系統會上傳到雲端辨識。
  3. 逐本核對：館藏分類、條碼（ISBN）、書名、文字作者、出版社、索書號。
  4. 按「已確認」。全部完成後匯出 Excel。
  5. 儲存滿 400 條或當月辨識額度用完，會停止新增／辨識；先匯出，再按指示處理。

相片會上傳到所選的雲端辨識服務（Google／OCR.space），不會存到本工具以外的伺服器。沒有網絡時不能辨識，但仍可查看及編輯已存資料。

索書號字母：R 宗教書；I 非宗教工具書／教師參考書；其餘中文 C、英文 E。雙語書由老師判斷（作者名中文→C、英文→E）。
